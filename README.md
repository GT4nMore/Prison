# Prison

A browser fly-through of **mp_prison**, my Call of Duty 4 custom map, built from the Radiant `.map` source.

Play: https://oisinmg.ie/Prison/

Controls: mouse to look, W A S D to fly, Space / C up and down, Shift for speed, scroll to change speed, R to respawn.

`docs/` is the published site (three.js viewer + `prison.glb`). It was generated with the converter in
[GT4nMore/Mullaghmore](https://github.com/GT4nMore/Mullaghmore) (`tools/`):

    python tools/build.py mp_prison prison ../Prison/docs
